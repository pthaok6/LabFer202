# Morrow Login

A clean, responsive login interface built with Next.js and TypeScript. The form
is intentionally presentation-only and does not submit or authenticate users.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Quality checks

```bash
npm run lint
npm run build
```

## Tech

- Next.js App Router
- TypeScript
- CSS Modules
- Tailwind CSS base setup from `create-next-app`
